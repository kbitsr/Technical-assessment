Este repositorio contiene la solución a una prueba técnica (`technical_test.ipynb`) desarrollada en **Google Colab** y procesada con Python, enfocada en la manipulación, análisis y gestión de datos.

## 📁 Contenido del Proyecto

* **Archivos generados / Resultados**: Datos procesados, reportes o artefactos exportados durante la ejecución de la prueba.

---

## 🛠️ Tecnologías y Herramientas

* **Entorno:** Google Colab / Jupyter Notebook
* **Lenguaje:** Python
* **Librerías principales:**
